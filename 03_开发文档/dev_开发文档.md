## 一、分类说明

`03` 段是**设计文档层**，把 `02` 段的需求翻译成可实现的技术方案。

**开发主管职责**：

1. 写设计文档：**先列设计子问题清单**（Q1/Q2…），每个子问题给决策 + 状态（✅已定 / ⬜待定）。
2. 明确接口契约、字段映射、错误处理矩阵、代码改动清单、测试方案。
3. 实现代码与测试 → git commit。
4. **不跳过设计子问题清单直接写码**；不自行变更需求范围。

**协作纪律**：

- 未定项标 `⬜` 并**升级项目主管拍板**，不得自行假设。
- 发现 `02` 段需求有问题，在对应处加 `⚠️ 反馈` 行交回产品经理，不直接改需求文档。
